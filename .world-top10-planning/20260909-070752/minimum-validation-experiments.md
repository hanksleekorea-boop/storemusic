# 최소 검증 실험

1. 직원 5명에게 두 버튼 플레이어를 30분 사용시켜 task completion/time-to-first-play를 기록한다.
2. 첫 상권 5개 매장에서 14일 동안 audible minutes, silent events, manual overrides를 익명 집계한다.
3. 3개 가격 문구(시간당/예상 월액/무음 미차감)를 무작위 노출하되 실제 PG 결제 전에는 청구하지 않는다.

실험 전 사장님 결정: 상권·매장 모집·결제 테스트 계정.

→ 이 실험의 뜻: 가설을 측정 가능한 행동과 연결하되 결과를 미리 쓰지 않는다.
