# 화면·상태 명세

- 공개 홈: 제품 정의, 가격 계산기, 가입 진입.
- 소유자 온보딩: 업종/영업시간/소리 선호/동네 동의 4문항. 인증 미연결이면 “미검증” 상태를 표시하고 재생 UI를 막지 않는다.
- 직원 플레이어: calm/lively 두 버튼, 현재 밴드·다음 전환만 표시. skip/search/playlist/equalizer/like는 제공하지 않는다.
- 오류/무음: restart → cache force play → owner push 순서.

→ 이 명세의 뜻: 화면 상태와 의도적으로 없는 기능을 동시에 고정한다.
